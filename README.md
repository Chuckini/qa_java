
#  qa_java — Unit-тестирование (Sprint 6)

Проект содержит юнит-тесты для учебного задания Sprint 6.  
В рамках проекта реализовано unit-тестирование бизнес-логики классов, связанных с семейством кошачьих.

- unit-тестирование
- изоляция зависимостей

## 🧩 Архитектурные решения

### Инъекция зависимостей (Dependency Injection)

Класс `Lion` реализован с использованием принципа **инъекции зависимостей**:
- зависимость `Feline` не создаётся внутри класса;
- объект `Feline` передаётся через конструктор;
- в тестах используется `Mockito` и `@Mock`.

Это позволило:
- избежать жёсткой связности между классами;
- упростить unit-тестирование;
- изолировать бизнес-логику от зависимостей.
